# Aquascape 3D

Game thiết kế và chăm sóc hồ thủy sinh 3D, phiên bản 2.1.

Chơi bằng Chrome hoặc Safari: https://r0bjn10-maker.github.io/aquascape-3d/

Chọn “Khám phá hồ mẫu” để bắt đầu. Hồ được lưu trên trình duyệt của thiết bị; dùng chức năng xuất JSON để sao lưu hoặc chuyển thiết bị.

Repository này chứa bản web đã build của Aquascape.
